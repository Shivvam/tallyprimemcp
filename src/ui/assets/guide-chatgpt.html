🤖 Connecting ChatGPT Desktop to TallyMCP Official Integration

ChatGPT Desktop (macOS and Windows) includes native Model Context Protocol support. You can link TallyMCP as a local MCP server to enable live financial queries.

  1. Open the ChatGPT Desktop app.
  2. Open Settings (Click your profile picture ▸ Settings, or press Ctrl + , / Cmd + ,).
  3. Select Integration or Developer settings.
  4. Click Add MCP Server.
  5. Fill in the server details:
    • Server Name: tally
    • Type: command or http/url
    • Command: tally-mcp with argument serve
    • Or HTTP URL: http://127.0.0.1:9190/mcp
  6. Click Save and toggle the integration ON.
⚙️ Configuration JSON

If using file-based configuration or ChatGPT Developer tools, use this configuration: 

{
  "name": "tally",
  "command": "tally-mcp",
  "args": ["serve"]
}
✅ Testing the ChatGPT Integration

In a new chat, prompt ChatGPT:

"Ask Tally what companies are currently open, and summarize our cash position."

ChatGPT will query your local TallyMCP server over loopback and display your accounting balances instantly.

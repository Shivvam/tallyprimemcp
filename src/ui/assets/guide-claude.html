⭐ Method 1: Add Custom Connector (In-App GUI) Recommended

Anthropic Claude Desktop and Claude.ai now allow registering Model Context Protocol servers directly through the user interface without touching any configuration files.

  1. Open Claude Desktop (or log in to Claude.ai in your browser).
  2. Open Settings (click your profile photo or press Ctrl + , / Cmd + ,).
  3. Click Connectors (or Integrations) in the left sidebar.
  4. Click Add custom connector. Claude will display "Step 1 of 2 — Connect Claude to your data and tools".
  5. Fill in the two required fields using the values below:
Add custom connector Step 1 of 2
Shown in your connectors list.
The loopback address where TallyMCP accepts JSON-RPC requests.
🛡️ Anthropic Security Notice: Only use connectors from developers you trust. Anthropic does not control which tools developers make available and cannot verify that they will work as intended or that they won’t change.
  1. Click Add or Connect to complete Step 2 of 2.
  2. Start a new chat in Claude. You will see the TallyMCP connector active with all 128 tools ready!
📦 Method 2: One-Click .mcpb Bundle

If you prefer drag-and-drop installation, you can use the pre-packaged tally-mcp.mcpb extension bundle.

  1. From the TallyMCP Dashboard, click Download tally-mcp.mcpb Bundle.
  2. Open Claude Desktop.
  3. Drag and drop the downloaded tally-mcp.mcpb file directly onto the Claude Desktop window, or navigate to Settings ▸ Developer ▸ Add MCP Bundle and select the file.
  4. Confirm the prompt. All tools will be enabled immediately.
⚙️ Method 3: Manual claude_desktop_config.json

For headless or stdio-based integration with Claude Desktop:

Config location: %APPDATA%\Claude\claude_desktop_config.json (Windows) or ~/Library/Application Support/Claude/claude_desktop_config.json (macOS) 

{
  "mcpServers": {
    "tally": {
      "command": "tally-mcp",
      "args": ["serve"]
    }
  }
}

Note for LAN users: If connecting to a remote Tally machine, pass ["serve", "--host", "192.168.1.50", "--port", "9000"].

✅ How to Verify in Claude

Once connected, test the connection by asking Claude:

"List all loaded companies in Tally and show me the closing balance of Cash and Bank accounts."

Claude will call tally_list_companies and tally_get_ledger_balance and return real-time financial figures straight from your TallyPrime!

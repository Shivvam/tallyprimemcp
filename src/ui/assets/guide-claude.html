Official instructions to connect Claude Desktop to your local TallyPrime data

⭐ Method 1: Local MCP stdio (Recommended & Most Secure) Official & 100% Local

Because TallyPrime runs locally on your machine, connecting via Claude Desktop's native local configuration file (claude_desktop_config.json) is the fastest, safest, and officially recommended method. Claude launches tally-mcp locally via standard I/O (stdio). No internet tunnels, public ports, or external URLs required!

🔒 Privacy Guarantee: In local stdio mode, your Tally accounting data never gets routed through any third-party tunnel or external server. Queries travel strictly within your own computer.

Step 1: Open the Claude Desktop Configuration File

There are two easy ways to open your configuration file:

Option A (Easiest — Directly inside Claude Desktop):

  1. Open Claude Desktop.
  2. In the top menu, click File ▸ Settings (or press Ctrl + , on Windows / Cmd + , on macOS).
  3. In the Settings window, click the Developer tab in the left sidebar.
  4. Click the Edit Config button.
  5. Claude Desktop will automatically open claude_desktop_config.json in your default text editor (Notepad, VS Code, Cursor, etc.).

Option B (Direct File Path):

  • Windows: Press Win + R, paste: 
    %APPDATA%\Claude\claude_desktop_config.json
    and press Enter. (Full path: C:\Users\<YourUsername>\AppData\Roaming\Claude\claude_desktop_config.json).
  • macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
  • Linux: ~/.config/Claude/claude_desktop_config.json

🎯 Step 2: Exactly Where to Paste (If your file already has settings)

Most Claude Desktop users already have an existing file with keys like "preferences" and "coworkUserFilesPath". Do NOT overwrite or delete your existing file! You only need to insert the "mcpServers" block inside the top-level { ... } braces:

Your Existing File ➔ How it Should Look After Editing: Valid JSON 
{
  "preferences": {
    "remoteToolsDeviceName": "laptop-uekcgrsc",
    "coworkWebSearchEnabled": true,
    ...
  },
  "coworkUserFilesPath": "C:\\Users\\ASUS\\Claude",
  "mcpServers": {
    "tallymcp.pro": {
      "command": "tally-mcp",
      "args": ["serve"]
    }
  }
}
💡 Key Checklist for JSON Editing:
  1. Add a comma (,) after the line right before "mcpServers" (e.g., right after "coworkUserFilesPath": "C:\\Users\\ASUS\\Claude").
  2. Paste the "mcpServers" block right before the final closing brace (}).
  3. Ensure there is no trailing comma after the "mcpServers" closing brace.

Snippet to Copy:

  "mcpServers": {
    "tallymcp.pro": {
      "command": "tally-mcp",
      "args": ["serve"]
    }
  }

Pro-Tip for Windows: If tally-mcp is not in your system PATH, use the full absolute path with escaped double backslashes: "command": "C:\\Users\\<YourUsername>\\AppData\\Local\\Programs\\TallyMCP\\tally-mcp.exe".

Step 3: Save and Force Restart Claude Desktop

Once you add MCP details to your config JSON file, you must force close and restart Claude Desktop. Simply closing the window leaves background worker processes active on Windows:

  • Force Close: Right-click the Claude icon in the Windows taskbar tray and click Quit, or kill it via Command Prompt: 
    taskkill /IM Claude.exe /F
  • Relaunch Claude Desktop: Start Claude Desktop from the Windows Start menu.
  • Verify Connection in Claude:
    1. Open any chat conversation in Claude Desktop.
    2. In the chat input bar at the bottom, click the ➕ (Plus) button.
    3. Click or hover over Connectors.
    4. Verify that you see tallymcp.pro listed there with active tools!
⚡ Method 2: One-Click .mcpb Extension Bundle Drag & Drop

If you prefer not editing JSON files manually, you can export a pre-packaged tally-mcp.mcpb bundle directly from the Companion UI:

  1. From the TallyMCP Companion UI Dashboard, switch to MCP Clients and click Download tally-mcp.mcpb Bundle.
  2. Open Claude Desktop.
  3. Either drag and drop the downloaded tally-mcp.mcpb file onto Claude Desktop, or navigate to Settings ▸ Developer ▸ Add MCP Bundle and select the file.
  4. Confirm installation. All 128 TallyPrime tools are connected!
⚠️ Common Mistake: "Add custom connector" Error Explained Cloud vs Local
Did you see this error?
"Claude connects from Anthropic’s servers, so it can’t reach a local address like this one. Enter a public https:// URL."

When you open Claude Desktop and navigate to Settings ▸ Connectors ▸ Add custom connector (titled "Step 1 of 2 — Connect Claude to your data and tools"), Claude is trying to connect via Anthropic's remote cloud infrastructure.

  • Why it rejects 127.0.0.1: Anthropic's cloud servers are located on the internet and cannot access 127.0.0.1 or localhost on your private machine.
  • Why you do NOT need public tunnels: Your TallyPrime data contains sensitive accounting records and financial balances. Exposing ports over third-party public tunnels (like ngrok) is unnecessary and poses security risks.
  • The Recommended Solution: Use Method 1 (Local MCP stdio) above! Open Claude Desktop ▸ File ▸ Settings ▸ Developer ▸ Edit Config, paste the configuration snippet, and restart. Claude connects directly to your local computer process via standard I/O (stdio). Zero tunnels, zero cloud exposure, 100% private, and works offline!

🔍 5-Step Robust Self-Diagnostic Checklist Self-Help & Diagnostics

Follow these 5 self-diagnostic checks in order if Claude Desktop does not show the hammer icon (🔨) or fails to query TallyPrime:

1 Check Claude Desktop Log Files

Claude writes MCP startup and runtime logs to disk. If an error occurs, it is recorded here:

  • Windows Log Path: 
    %APPDATA%\Claude\logs\mcp.log
    (Also check: %APPDATA%\Claude\logs\mcp-server-tally.log)
  • macOS Log Path: 
    ~/Library/Logs/Claude/mcp.log
  • Linux Log Path: 
    ~/.config/Claude/logs/mcp.log

2 Verify TallyPrime XML/ODBC Connectivity Settings

TallyPrime must be configured to accept local XML-over-HTTP requests:

  1. Open TallyPrime.
  2. Press F1 (Help) ▸ Settings ▸ Connectivity.
  3. Under Client/Server configuration, ensure:
    • TallyPrime acts as: Both (or Server)
    • Enable ODBC: Yes
    • Port: 9000
  4. If you changed settings, press Enter to save and restart TallyPrime.
  5. Browser Test: Open http://127.0.0.1:9000 in Chrome/Edge. If Tally is running, it will return an XML response.

🌐 Connecting to Tally across LAN: How to find machine IP address (run ipconfig)

If TallyPrime is hosted on a separate machine on your local office network or Wi-Fi (e.g. an accounting server PC):

  1. On the computer running TallyPrime, press Win + R, type cmd, and press Enter to open Command Prompt.
  2. Run:
    ipconfig
    and press Enter.
  3. Look for IPv4 Address under your active adapter (e.g. 192.168.1.50).
  4. In the Companion UI (Step 1) or your MCP config, set Host to that IP address (e.g. 192.168.1.50) and Port to 9000.

3 Ensure At Least One Company is Loaded in Tally

If the Gateway of Tally displays "Select Company" without an active company loaded, all accounting queries (ledgers, day book, trial balance) will return empty. Make sure your active company is open in Tally before asking Claude.

4 Terminate Stale Claude Desktop Processes

Closing the Claude window does not terminate the background process on Windows. If Claude hasn't picked up config changes: 

taskkill /IM Claude.exe /F

Run this in Command Prompt or PowerShell, then relaunch Claude Desktop from Start.

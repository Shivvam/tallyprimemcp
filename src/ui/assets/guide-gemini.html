Connect Google Gemini tools and agents to TallyPrime

🌐 Gemini MCP Protocol Configuration gemini-3.8-flash

To give Gemini access to your TallyPrime tools, configure your user or workspace MCP configuration file.

Config location: ~/.gemini/mcp_config.json 

{
  "mcpServers": {
    "tally": {
      "command": "tally-mcp",
      "args": ["serve"]
    }
  }
}
⚡ LAN / Remote Tally Server Support

If TallyPrime is hosted on a different computer in your office or LAN (e.g. 192.168.1.50:9000), update your arguments: 

{
  "mcpServers": {
    "tally": {
      "command": "tally-mcp",
      "args": ["serve", "--host", "192.168.1.50", "--port", "9000"]
    }
  }
}
✅ Testing the Gemini Integration

Run a test command in your Gemini environment:

"Fetch the trial balance summary from TallyPrime and list any accounts with negative cash balance."

Gemini will invoke tally_get_trial_balance and structure the result cleanly.

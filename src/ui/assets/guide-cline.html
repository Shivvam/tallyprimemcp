⚙️ Cline MCP Server Configuration VS Code Extension

Cline (and Roo Code) runs as an autonomous agent in VS Code capable of executing accounting operations with your approval.

  1. In VS Code, click the Cline icon in the Activity Bar.
  2. Click the MCP Servers icon (server icon at the top of the Cline view).
  3. Click Configure MCP Servers to open cline_mcp_settings.json.
  4. Add the tally server configuration:
{
  "mcpServers": {
    "tally": {
      "command": "tally-mcp",
      "args": ["serve"],
      "disabled": false,
      "autoApprove": []
    }
  }
}
  1. Save the file. Cline will immediately connect to tally-mcp and index all 128 tools.
🛡️ Safety & Approval Notes

By default, all write operations (like creating voucher drafts) in TallyMCP require manual confirmation. Leaving "autoApprove": [] empty ensures that Cline always asks your explicit consent before modifying any ledger or voucher.

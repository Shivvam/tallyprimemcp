🌊 Cascade MCP Integration Codeium Windsurf

Windsurf supports Model Context Protocol plugins for its Cascade assistant.

  1. Open Windsurf.
  2. Open settings or open the global configuration file:
    ~/.codeium/windsurf/mcp_config.json
  3. Paste the following JSON block:
{
  "mcpServers": {
    "tallymcp.pro": {
      "command": "tally-mcp",
      "args": ["serve"]
    }
  }
}
  1. Save the file.
  2. In Windsurf, open Cascade (the AI panel) and click the refresh icon next to MCP tools.
✅ Testing with Windsurf Cascade

Ask Cascade:

"Check TallyPrime to see the list of active stock groups and inventory items."

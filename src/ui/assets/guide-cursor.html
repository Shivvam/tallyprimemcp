📁 Option 1: Workspace Config (.cursor/mcp.json) Recommended

To enable TallyPrime tools across any codebase or workspace in Cursor, create a file named .cursor/mcp.json in the workspace root: 

{
  "mcpServers": {
    "tally": {
      "command": "tally-mcp",
      "args": ["serve"]
    }
  }
}
🌐 Option 2: Global Cursor Settings

To make Tally tools available in every project automatically:

  1. Open Cursor.
  2. Open Cursor Settings (press Ctrl + Shift + J / Cmd + Shift + J, or gear icon).
  3. Select Features ▸ MCP.
  4. Click + Add New MCP Server.
  5. Enter:
    • Type: command
    • Name: tally
    • Command: tally-mcp serve
  6. Save. The status light next to tally will turn green indicating tools are ready.
✅ Testing with Cursor Composer

In Cursor Composer (Ctrl + I / Cmd + I), mention @tally:

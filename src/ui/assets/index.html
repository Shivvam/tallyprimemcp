📑 Full .mcpb Guide ↗

How to use .mcpb in Claude Desktop:

  1. Click Download tally-mcp.mcpb Bundle above.
  2. Open Claude Desktop.
  3. Either drag and drop the downloaded tally-mcp.mcpb file onto Claude Desktop, or go to Settings ▸ Developer / Extensions ▸ Add MCP Bundle and select the file.
  4. Confirm installation. All 128 TallyPrime tools are connected and available in your chat!

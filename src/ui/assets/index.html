🌐 TallyPrime Target URL (Localhost or LAN)

Guide: Find IP (ipconfig) ▾ Step 1 of Setup

Connect to TallyPrime on this computer (127.0.0.1) or across your local area network (LAN IP, e.g. 192.168.1.50). Changes are saved to config.toml. 🔍 How to know IP address of the machine running Tally? (Run ipconfig) ▾

💻 How to Know the IP Address of the Machine Running Tally:

If TallyPrime is running on another machine across your local network (e.g. office server or desktop PC), find its LAN IP address by running ipconfig on that machine:

  1. On the computer running TallyPrime, open Command Prompt (Press Win + R, type cmd, and press Enter).
  2. In the Command Prompt window, type:
    ipconfig
    and press Enter.
  3. Locate the IPv4 Address line under your active connection (e.g. Wireless LAN adapter Wi-Fi or Ethernet adapter). It usually looks like 192.168.1.50 or 192.168.X.X.
  4. Enter that IP address in the Tally Host / IP Address field below (with Port 9000), then click Save & Connect!
💡 Prerequisite: Make sure TallyPrime on that machine has Connectivity enabled (F1 ▸ Settings ▸ Connectivity ▸ Both or Server on port 9000) and Windows Firewall allows port 9000. Detailed LAN Guide ↗
Quick Presets:
💡 How to Enable XML/ODBC Server in TallyPrime:
  1. In TallyPrime, press F1: Help ▸ Settings ▸ Connectivity.
  2. Set Client/Server configuration: Tally acts as Both (or Server).
  3. Set Port: 9000.
  4. Press Ctrl + A to save and restart TallyPrime if prompted.
  5. Open at least one Company in TallyPrime, then click Ping or Save & Connect above!

⚠️ Got "Claude connects from Anthropic’s servers..."?

Local vs Cloud
Why did this happen?
Claude's in-app Connectors GUI (under Settings ▸ Connectors) connects from Anthropic's cloud servers, so Anthropic strictly rejects 127.0.0.1 / localhost addresses and asks for a public URL.
• Do NOT expose your accounting data via public tunnels (like ngrok): Your financial books should stay 100% private and local.
• The Official Solution: In Claude Desktop, go to File ▸ Settings ▸ Developer ▸ Edit Config and paste the Local MCP snippet above. It runs 100% locally via stdio with zero cloud exposure!
